# Sistema de Gestão de Veículos

Aplicativo desenvolvido com Microsoft Power Apps para gerenciamento de informações de veículos, com integração ao SharePoint.

## Funcionalidades

- Cadastro de veículos
- Pesquisa de veículos
- Edição e exclusão de registros
- Exibição de fotos dos veículos
- Armazenamento de informações em lista do SharePoint
- Cálculo automático do IPVA conforme o ano de fabricação

## Tecnologias utilizadas

- Microsoft Power Apps
- Power Fx
- Microsoft SharePoint
- Lógica de programação
